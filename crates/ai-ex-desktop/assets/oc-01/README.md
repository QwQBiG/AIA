# 一号人物素材

一号人物使用项目作者提供的 OC。银灰短发、灰紫眼睛、画面右侧的两枚淡紫发夹、同侧眼下小痣和淡紫领结沿用认可主图。人物称呼与人格仍由用户的角色设定决定。

| 文件 | 用途 |
| --- | --- |
| `portrait.png` | 认可主立绘，原文件保留，固定主体与半身/全身展示 |
| `blink.png` / `speaking.png` | 对齐主图的状态素材，运行时只绘制独立校准的眼部/嘴部区域 |
| `expressions.png` | 原六格表情参考，整张静态展示 |
| `welcome.png` / `focus.png` / `success.png` / `encourage.png` | 原欢迎、专注、完成庆祝、温柔鼓励动作图，静态素材册展示 |

六份原始立绘与参考图保持文件内容不变。所有图片保留原画背景；当前未提供透明裁切、骨骼绑定或六表情自动映射。渲染坐标归 `oc_portrait_patches.rs` 所有，与初始伙伴的素材和坐标分开。
