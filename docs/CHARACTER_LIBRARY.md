# 角色收藏与来源

在“角色设置（新手）→ 角色收藏（选择 / 新建）”中，可以直接选择角色，不必每次填写文件路径。首次使用提供“小艾”和“阿星”两份内置示例。

## 选择和创建

- **载入草稿**：将收藏的设定放进编辑区。当前角色继续运行，检查后通过原有预览确认流程应用。
- **新建角色**：生成新的档案 ID，创建可自由编辑的“新伙伴”。完成编辑后可以收藏、导出或应用。
- **复制为独立角色**：保留原设定、作者与使用条件，生成全新的档案 ID 和版本 1。它使用独立的记忆范围；修改名称不会替代身份隔离。
- **收藏当前草稿**：保存编辑区中的人格与作者信息，不要求先应用。也可先从[角色包](CHARACTER_PACKS.md)导入，再收藏。

可以按名称、档案 ID 或作者搜索。列表中“正在使用”表示该份人格快照与当前服务相同；相同档案 ID 的其他版本或设定显示为“同一角色的其他设定”。

预览确认期间暂停修改草稿，取消后可以继续编辑，确保应用的内容与预览一致。

## 保存版本与移出

收藏保存设定副本，原角色包移动或删除后仍可载入。相同档案 ID、相同版本且内容相同的收藏会复用；同一身份与版本已有不同内容时，拒绝覆盖。编辑后可以使用“版本 +1”，再收藏新的版本。

每个本机列表最多保存 32 份版本，序列化数据不超过 2 MiB；每份设定继续遵守角色包限制。移出只删除这份列表记录，不删除原角色包、当前服务角色或它的记忆。“撤销移出”可恢复本次会话最后移出的记录；若列表已满或出现版本冲突，撤销会提示处理冲突。

收藏属于本机桌面，不按服务配置分组；可以在不同服务中复用设定，经历仍留在各自服务。打开列表或载入草稿不会自动切换角色，也不会改变已选择的[启动组合](SCENE_PACKS.md)。

## 看清当前设定来自哪里

角色面板分别显示当前角色和编辑草稿的来源：角色包路径、角色收藏、独立副本、场景，或服务同步。服务没有提供包来源时会明确显示未知来源，不根据名称猜测。

编辑区会比较载入时的快照，标出“已修改”；应用后，当前来源会保留原来源并标明包含本次编辑。收到另一个客户端改变的角色快照时，会改为服务同步来源，并清除没有依据的旧作者信息。

这些是当前桌面掌握的设定来源，不是作者真实性认证，也不包含每个字段的配置覆盖历史。模型、声音和行为的逐字段来源与回退仍在后续计划中。

## 本机存储与验证

收藏使用桌面设置存储，保存角色快照和来源说明。它不附带图片、声音、模型凭据或私人记忆；分享角色继续通过角色包导出。收藏读取失败时不在普通保存中改写原记录；用户重新编辑收藏时，会先在本机设置中保留一份带独立标识的原始记录备份。备份恢复界面尚未提供。

自动测试覆盖版本冲突、保存重开、移出与撤销、容量限制、损坏记录保留与备份、原始作者信息、独立身份、载入草稿不切换服务，以及对应应用确认后的来源更新。界面验证使用无窗口环境，完整前台交互仍待单独验收。
