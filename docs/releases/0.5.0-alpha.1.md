# 0.5.0-alpha.1 · 记忆工作台与连续表达

这一版让角色留下的经历可以直接查看和管理，并让人物在思考、表达与等待之间更自然地过渡。桌面与服务继续使用 Rust，记忆管理通过控制协议进入运行时，不由界面直接编辑存储文件。

## 记忆工作台

- 顶部增加“记忆”页，支持关键词、分类、分页、来源和原文查看。新建编辑器默认折叠，展开“记下一件事”保存笔记；点击“更正”自动展开并定位输入区。
- 用户明确保存的笔记与用户更正单独标记；自动记录显示“未经确认”。确认笔记优先进入当前角色召回，不要求复用相同关键词，仍受总条数上限限制。
- 更正替换一条记录的原输入并清除该条旧回复；遗忘须核对后确认，只删除所选记录。跨角色请求、过期记录版本和活动回合中的管理会被拒绝。
- 新建、更正和遗忘持久化成功后，当前短期上下文与聊天显示重新开始，聊天输入草稿保留。成功应答附带快照序号边界，迟到旧事件不会重新显示被清理的对话。
- 笔记草稿在本次会话中按角色分别保留，切换后的旧响应不能覆盖新角色列表。写入结果不明时先刷新核对，禁止直接重复保存；遗忘确认期间保护编辑草稿。
- 连接设置增加“启用长期记忆”。新配置默认启用，已有选择和存储路径保留；保存后重启服务生效，关闭开关不会删除记录。

列表按真实 JSON 大小限制分页，超长单条明确显示为片段；更正从完整事实重新写起。状态与记忆应答中的过长诊断、播放文字会显示省略号，不改变事件身份和状态；读取列表不会推进聊天游标。

## 连续表达

`PresentationAnimator` 将运行状态投影为连续眉形、眼形、嘴角、腮红和视线参数，正口型采样也做轻量平滑。内置人物仍有头发、面部、肩膀和服装，图片外形与可选 VTS 保留独立适配。

静音、倾听、失同步、断线、打断、停止、故障和减少动态效果立即闭嘴，不延长旧音节。惊讶通过眼形和眉位表现，不再强制无声开口；小口型与牙齿出现更渐进。修复长期运行时每 120 秒统一重置动画造成的跳变，不引入随机主动行为。

## 开始体验

完整解压 `AIex-Windows-x64-0.5.0-alpha.1.zip`，双击 `AIex.exe`。先从“先体验外形”检查人物，再连接自己的模型；在“记忆”页记下一条测试笔记，依次更正、取消一次遗忘，再确认遗忘。

具体操作见[约五分钟体验与深度验收](../MANUAL_TEST_PLAN.md)，来源、召回与遗忘边界见[记忆工作台](../MEMORY_WORKSPACE.md)。

## 验证范围

自动回归通过 **311 项测试**：核心 workspace 全功能 230 项、独立桌面 81 项。真实音频测试与可选离屏导出在默认回归中忽略，聊天与记忆页的宽窄窗口导出已单独执行并检查。两个工作区的格式检查及严格 Clippy 检查通过，31 个包的依赖检查及违规探针通过；真实服务进程测试使用本地模拟模型。

- 存储与运行时：来源和旧记录兼容、确认笔记排序与召回上限、身份/版本冲突、分页与长记录、持久修改失败保护、活动回合与停止边界。
- 协议与服务：真实进程配合本地模拟模型检查修改后的上下文与召回；记忆应答、时间戳和 JSON 字节预算覆盖正常与错误路径。
- 桌面：列表与草稿切换、未知结果保护、过期应答与旧事件屏障、设置开关、折叠编辑器、宽窄窗口与长文确认框的离屏交互检查。
- 表现：不同刷新率的连续性、所有闭嘴条件、长时间运行与无效时钟；人物及图片绘制的有效网格检查。
- 分发：便携包校验通过，包括两个 Windows 程序的无界面实际启动、完整包文件清单、移除开发工具路径后的独立运行、不同启动目录、中文与空格路径、缺失文件及重复打包的错误路径。

真实窗口操作、模型长期遵循偏好的表现、麦克风、扬声器同步与设备延迟仍需用户整机验收。离屏图像与模拟模型测试不能替代这些结果。

## 更新与限制

桌面和服务应一起更新。旧记忆没有来源或记录版本时，按自动记录和版本 1 读取；原有角色 ID、分类和私人记录保留。关闭程序后把新版解压到新目录，按[便携版说明](../PORTABLE_WINDOWS.md)沿用配置与记忆，避免分发默认配置覆盖个人设置。

单条遗忘不等于概念级全局遗忘：相同信息在其他记录、角色设定或外部模型中可能仍存在，需要分别处理。自动记录不等于确认事实，确认笔记也不等于独立核实。当前存储不保证多个独立进程同时修改同一 JSONL 的事务一致性。

相同角色重启后可继续使用持久记忆，但完整聊天显示与全部短期历史恢复尚未实现。网页、桌面悬浮、VRM 3D、声音/行为包、交互对象分区与关系推导仍在后续路线中。VTS/OBS 尚未接入原生播放时间线；现有口型按振幅驱动。
