# 0.2.0-alpha.1 · 数字伙伴工作室 Alpha

发布日期：2026-09-06。此版本作为本轮阶段交付点；推送 GitHub 后停止继续开发，后续工作等待用户重新启动。

这是一个可以组合角色与外形、保存场景、恢复身份并进行对话的 Rust 桌面工作室。版本定位为 Alpha：已经串起当前支持的使用路径，完整数字人路线中的网页、3D、声音/行为包和更深入的关系记忆仍在后续计划中。

## 这一版交付什么

- **角色可以积累和复制**：内置两个示例，支持新建、独立复制、收藏多个设定版本、搜索、导入导出、预览应用和查看来源。复制独立角色时分配新身份。
- **身份与外形分开**：同一角色换外形沿用记忆；换角色隔离持久记忆并清空短期上下文。分享角色与场景不携带私人记忆或密钥。
- **多种外形可选**：内置 2D 伙伴、光球、自定义 PNG/JPEG 表情图片，也可以隐藏外形；VTube Studio 保留为可选适配器。
- **场景能保存和重载**：导出已应用的角色、外形与显示偏好，图片随场景携带；完整资源校验和服务确认成功后再切换外形。可以固定一份启动组合。
- **原生表达跟随声音**：逐句字幕、表情和 PCM 能量口型跟随实际播放。生成完成后表情继续保留到该句播完；新输入或打断取消旧语音，迟到状态不会重新激活它。
- **运行边界清楚**：首次设置生成本机配置；桌面可启动自己的后台服务并随关闭退出，也可认证后复用已有服务。离线工作室可以在没有模型与音频服务时设计外形。

## 开始使用

源码构建需要 Rust 1.96。先在仓库根目录完成两个构建，再打开桌面入口：

```powershell
cargo build -p ai-ex-service --all-features --locked
cargo build --manifest-path crates/ai-ex-desktop/Cargo.toml --locked
```

Windows 用户之后可双击 `AIex-Desktop.cmd`。首次设置选择模型地址和凭据；要使用语音，需要另外配置并运行 GPT-SoVITS 及参考音频。模型、语音服务和模型资源没有随源码内置。

只设计外形时使用：

```powershell
cargo run --manifest-path crates/ai-ex-desktop/Cargo.toml --locked -- --preview
```

建议按以下顺序体验：

1. 在角色收藏中载入示例，或复制一个独立角色，修改设定并预览应用。
2. 选择伙伴、光球或图片角色，调整配色、尺寸和动态效果。
3. 对话；启用语音后观察“正在说”字幕和外形，使用“打断”停止剩余声音。
4. 将当前组合导出到新目录，也可以设为启动组合。连接已有服务时，启动组合会先请求确认。
5. 从导出的场景重新导入；导出前仍未应用的草稿不会混入当前组合。

详细说明：[角色收藏](../CHARACTER_LIBRARY.md)、[图片外形包](../APPEARANCE_PACKS.md)、[场景组合](../SCENE_PACKS.md)、[声音与表达](../SPEECH_PRESENTATION.md)、[桌面使用](../DESKTOP_USER_GUIDE.md)。

## 验证与边界

本轮使用后台测试和无窗口绘制验证，不操作用户正在使用的桌面，不播放扬声器或采集麦克风。最终本地验收结果：

| 检查 | 结果 |
| --- | --- |
| Workspace 全 feature 测试 | 191 项通过；1 项真实音频设备测试默认忽略 |
| 独立桌面测试 | 40 项通过，包含无窗口字幕绘制 |
| Workspace 与桌面严格 Clippy | 均通过 |
| 原生服务与桌面构建 | 均通过，使用 Rust 1.96.0 |
| Allman 风格与依赖边界 | 140 个 Rust 文件、30 个 workspace 包通过 |
| 清单、锁文件、版本说明链接 | 解析/目标检查通过，外部依赖版本未改变 |

GitHub 检查已扩展为全 feature 核心测试与独立桌面测试/构建；远程运行结果以对应提交的 Actions 页面为准。

新增确定性测试覆盖运行时、舞台、语音队列与控制快照的连通，重复语句身份、生成完成后的情绪、取消后的迟到状态、新旧回合隔离、断线恢复、长句消息大小和字幕实际绘制。设备测试保留为默认忽略项；这些测试使用模拟播放进度，不能替代真实设备上的时延测量。

已知限制：

- VTS 和 OBS 仍按生成时的舞台动作调度，未接入新的播放时间线；本版的逐句同步范围是原生外形与桌面字幕。
- 尚无网页/VRM 身体、词级字幕、音素口型、表情平滑过渡、图形化声音/行为包和逐字段配置来源回退。
- 记忆已有身份隔离和管理基础，确认式事实学习、可追溯关系演进仍未完整实现。
- 真实模型、真实音频设备、完整首次设置点击流程、跨机器场景迁移与慢适配器下的打断时延仍需实机验收。队列背压及外部舞台调用可能影响控制响应，应继续作为后续可靠性重点。
- 本版增加播放进度与取消事件，桌面和服务应一起更新。角色、图片与场景清单保持 schema v1；旧包仍可导入。
- GitHub 交付为源码分支与版本标记；本轮没有制作安装程序。首次构建需要下载依赖，本地模型和语音资源需要另外提供。
