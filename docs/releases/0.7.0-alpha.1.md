# 0.7.0-alpha.1 · 一号人物与素材工作室

项目作者的 OC 成为默认一号人物。保留认可主立绘、银灰短发与淡紫细节，可切换半身近景或全身立绘；原来的初始伙伴仍可选择，人物外形与人格、记忆各自保存。

## 本版变化

- 内置人物目录使用稳定 ID；OC 与初始伙伴各自管理纹理、局部坐标和瞬时状态。
- OC 主体保持固定，以独立眼部与嘴部贴层提供眨眼、说话；停止、静音、断线与减少动态效果立即收口。
- 离线预览新增 OC 素材册，可查看正式立绘、六表情参考和四张动作图，选择只影响浏览内容。
- 场景 v2 记录 OC 人物与构图，支持保存、载入和启动恢复；旧 v1 场景明确恢复初始伙伴，未知人物在角色应用前被拒绝。
- Windows 便携包继续完整解压、双击 `AIex.exe` 使用；所有内置素材随程序提供。

## 体验顺序

1. 解压本版便携包，双击 `AIex.exe`，选择“先体验外形”。
2. 查看一号人物，切换“半身近景 / 全身立绘”，再展开“OC 素材册”翻看参考图。
3. 选择初始伙伴试试原有情绪；返回一号人物，在表达状态启用“减少动态效果”，检查立即闭嘴。
4. 从底部“开始对话”连接自己的模型。保存 OC 场景并重新载入，确认人物与构图保持一致；再验证启动组合。

完整操作和反馈方式见[整体验收流程](../MANUAL_TEST_PLAN.md)。

## 当前限制

OC 的六表情参考和四张动作图是静态素材，没有自动映射到实时情绪。眼口为离散局部状态贴层，不是 Live2D、骨骼动画或连续音素口型；全身模式保持构图稳定。图片保留原画背景，舞台配色不重新绘制衣服。

场景 v2 需要 0.7 或更新的兼容程序；角色包、图片外形包和服务控制协议不随此变动升级。模型、声音和私人记忆不随场景导出。真实模型、音频设备、前台操作和跨机器体验仍需整机验收。
