# 0.3.1-alpha.1 · Windows 便携体验版

本版把首次体验缩短为“完整解压 → 双击 AIex.exe → 选择体验方式”。桌面与后台服务一起分发，普通使用不再依赖源码构建。

## 交付内容

- 原生欢迎页：离线外形体验、连接模型、已有配置入口。
- 便携目录定位：从程序位置读取 `data` 配置，避免快捷方式工作目录导致找不到文件。
- 中文启动错误窗口、取消设置正常退出、后台服务日志文件。
- 默认开启本地记忆；声音、麦克风和外部表现扩展默认关闭。
- 可重复使用的 Windows 打包脚本、程序包检查与 SHA256 校验文件。
- README、架构说明和界面测试清单；源码与设备深度验收作为可选部分。

## 验证范围

核心 198 项、桌面 44 项自动测试通过；核心与桌面均通过格式和严格静态检查。架构检查覆盖 31 个包，并确认故意注入的越界依赖会被拒绝。真实音频设备测试 1 项默认忽略。

分发检查覆盖两个 release 程序的版本、Windows x64 格式与系统依赖，以及压缩包内容、无窗口安装检查和重复目标拒绝覆盖。图形界面按钮通过无窗口事件测试验证，未操作用户的桌面。

真实窗口操作、模型服务、声音和麦克风需要用户在自己的使用环境验收。开发验证没有打开用户桌面上的程序窗口或操作输入设备。

## 已知边界

- 程序包不包含模型、语音引擎或声音资源；真实对话需要自己的模型服务。
- 云端密钥不落盘，未设置环境变量时下次启动需要再填写。
- 配置与记忆跟随 `data`；角色收藏和部分偏好仍在本机桌面设置中。
- 外形体验在原生应用窗口内；桌面悬浮宠物、网页载体和 VRM 3D 尚未实现。
- 便携包必须完整解压，两个 EXE 和 `data` 不能拆开使用。

使用步骤见[便携版说明](../PORTABLE_WINDOWS.md)，测试见[整体验收流程](../MANUAL_TEST_PLAN.md)。上一版的对话取消与恢复能力继续保留，见[0.3.0 说明](0.3.0-alpha.1.md)。
