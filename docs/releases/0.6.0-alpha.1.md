# 0.6.0-alpha.1 · 二次元外形与轻色工作室

默认人物换成精细二次元插画，欢迎、预览、设置和聊天重新整理为暖白与淡紫工作室。完整解压后双击 `AIex.exe`，先体验外形即可看到人物，无需下载模型或手工导入素材。

## 内置人物

- 八张同画幅 PNG 直接内嵌在桌面程序中，包含陪伴、眨眼、说话、思考，以及开心、低落、生气、惊讶素材。
- 插画保留浅色背景，呈现为圆角画面卡。固定主体配合局部表情状态帧与细微呼吸，舞台点缀只影响装饰，不改变服装。
- 正式对话的说话帧依据实际播放，静音、打断、断线和减少动态效果不保留旧说话帧；离线预览使用明确标注的示意状态。
- 自选 PNG/JPEG 外形、透明 PNG、隐藏外形和原有场景继续可用，外形切换不改变角色身份与记忆。

这不是 Live2D、骨骼动画或实时面部变形；自定义图片包仍按清单切换整张图片，不提供图形化分层编辑器。

## 工作室界面

欢迎页先提供离线体验，连接设置把伙伴名称、记忆与模型分组。预览把人物舞台与状态编辑分开，底部保留开始对话与返回入口。

聊天使用独立的对白卡片和固定输入区，宽屏人物舞台与对话并排，窄屏可折叠人物。角色页分别编辑外形与相处方式。原有 Enter 换行、Ctrl+Enter 发送、中文输入法保护、草稿保留与未知结果核对继续保留。

## 开始测试

下载 `AIex-Windows-x64-0.6.0-alpha.1.zip`，完整解压后双击 `AIex.exe`。先用五分钟检查人物、表情、隐藏与小窗口操作，再接入自己的模型；准备声音和麦克风可稍后进行。

具体操作见[整体验收流程](../MANUAL_TEST_PLAN.md)。旧数据迁移见[便携版说明](../PORTABLE_WINDOWS.md)，自定义素材见[图片外形包](../APPEARANCE_PACKS.md)。

## 验证记录

本版完成以下验证：

- 核心全功能测试 230 项通过；桌面与渲染示例测试 111 项通过，包含表情组合、静音与打断闭嘴、资源缓存、中文输入法和小窗口真实裁剪边界。
- 两个工作区的格式检查和严格静态检查通过；31 个包的依赖方向检查通过，主动加入错误依赖的探针按预期拒绝。
- 五个可选离屏导出检查分别通过；欢迎、预览、设置、聊天和记忆的宽窄界面均已查看。八张 1024 × 1536 素材以及八状态实际渲染已检查。
- Windows 正式程序构建和便携包自检通过。程序包在不同工作目录、带中文及空格的路径、仅保留系统 PATH 的环境中可完成安装自检与服务动作回放。
- 缺少服务程序时明确报错；重复打包拒绝覆盖。分发包只含五个必要文件，配置与分发模板一致，自检不初始化私人数据。

一项需要真实输出设备的核心测试保留为未执行。便携 ZIP 为 31,538,571 字节，随包提供 SHA256 校验文件。

真实窗口操作、模型长期表现、文件拖放、麦克风与扬声器同步仍需用户整机验收。离屏截图不能证明实际设备延迟。

## 更新边界

桌面与服务一起更新，先将新版解压到新目录，保留旧目录。配置、私人记忆与已有场景继续使用原有格式；不要用分发默认配置覆盖自己的 `data`。

内置人物不是透明桌面悬浮窗口。网页载体、VRM 3D、声音与行为包、完整聊天历史恢复仍在后续路线中。VTS 与 OBS 尚未接入原生播放时间线；记忆仍按单条记录管理，不提供概念级全局遗忘。
