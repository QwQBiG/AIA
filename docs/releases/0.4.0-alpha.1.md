# 0.4.0-alpha.1 · 人物与对话工作室

这一版重新整理桌面工作室：默认以人物和对话为主，角色、场景与设置拥有独立入口。内置外形改为半身人物，原有图片角色与 VTube Studio 继续作为可选载体。

## 使用体验

- **人物立绘**：头发、五官、颈部、肩膀和服装共同构成人物轮廓；配色、表情、眨眼、视线与口型继续由同一表现状态驱动。减少动态效果仍可用。
- **旧外形兼容**：界面移除光球。旧偏好或场景中的 `orb` 读取为人物，重新保存时使用 `companion`；角色身份与记忆范围保持原值。
- **对话布局**：聊天、角色与外形、场景、设置分开；宽窗口并排显示人物和消息，窄窗口调整布局，输入区保持可达。
- **输入保护**：Enter 换行，Ctrl+Enter 或“发送”提交；中文输入法候选确认不会直接发送。连接尚未同步时可先写草稿。
- **程序内切换**：预览中可以直接开始对话或返回首页；聊天内可回到首页或连接设置。预览和聊天共用外形偏好。
- **连接恢复**：启动失败页提供设置与离线预览入口；自己启动的后台退出后显示原因。已填写的密钥只在当前进程中复用，配置改变后不沿用旧密钥。

## 代码与架构

启动会话、窗口导航、聊天布局、消息编辑、主题与人物绘制分开维护。桌面继续通过认证控制协议访问独立 Rust 服务，不直接创建模型或声音设备。

状态快照需要先补齐对应的文字事件，防止刷新时跳过聊天内容。短暂断线尝试补回未接收事件；事件已超出缓冲范围或服务重启时，保留已显示文字并明确提示记录不完整。

服务只在运行时确认接纳消息后返回接受应答，等待队列满时直接报告失败。桌面把明确未发出的消息保留为可恢复草稿；普通请求和打断/急停分别发送，关闭窗口会取消尚未完成的网络等待。

返回首页或修改设置会结束当前聊天窗口，回收它自己启动的后台服务。独立运行并被复用的服务仍由其启动者管理；修改它的配置需要重启该服务。

## 开始测试

完整解压 Windows 程序包后双击 `AIex.exe`：先选“先体验外形”，调整人物并尝试表情，然后直接点击“开始对话”。准备好模型连接后，按[整体验收流程](../MANUAL_TEST_PLAN.md)检查消息、打断、角色与场景。

本版通过 204 项核心测试与 66 项桌面测试、默认格式检查、严格 Clippy 和 31 个包的依赖检查。另单独执行了宽窄聊天窗口的离屏图像测试；内置人物覆盖表情、配色及旧配置迁移。测试使用本地模拟服务和无窗口界面。

正式程序包通过无开发工具路径、不同工作目录、中文及空格路径、旁置服务缺失、重复打包拒绝覆盖等检查。包内只有两个程序、便携标记、使用说明和默认配置；安装检查不会初始化私人记忆或控制令牌。

真实窗口操作、外部模型回答、麦克风及声音同步仍需用户整机验收；真实音频测试默认跳过。自动检查通过不代表这些项目已经验收。

## 范围

人物为内置矢量半身立绘，也可导入自己的 PNG/JPEG 表情组。网页载体、桌面悬浮、VRM 3D、声音/行为包编辑器和长期记忆管理界面仍在后续路线中。

配置和长期记忆位于便携包 `data`；外形偏好、角色收藏与启动组合仍使用本机桌面存储。跨电脑需导出角色或场景。云端密钥不写入配置文件，下次启动需重新提供或使用配置指定的环境变量。
