# 🎙️ 全双工对话模式使用指南

## 什么是全双工模式？

全双工对话模式是AI VTuber系统的核心功能，它允许：

- **实时语音识别**: 系统持续监听您的语音输入
- **智能打断**: 您可以随时打断AI的回答
- **自然对话**: 像真人对话一样的交互体验
- **低延迟响应**: 200ms内响应您的打断

## 🚀 快速开始

### 1. 启用全双工模式

在GUI界面中：
1. 切换到 "🎯 基础功能" 标签页
2. 勾选 "🎙️ 全双工对话模式"
3. 系统会自动初始化语音识别

### 2. 硬件要求

**推荐配置**:
- 🎧 **耳机**: 强烈推荐使用耳机避免回音
- 🎤 **麦克风**: 清晰的麦克风输入
- 💻 **性能**: 4GB+ RAM，支持实时处理

**不推荐**:
- 🔊 扬声器 + 麦克风组合（容易产生回音）

### 3. 使用方法

1. **开始对话**: 直接对着麦克风说话
2. **查看识别**: 实时文本会显示在界面上
3. **智能打断**: AI回答时可以直接说话打断
4. **自然交流**: 像和真人对话一样自然

## ⚙️ 配置选项

### 语音识别引擎

系统支持多种ASR引擎：

1. **Whisper** (推荐，Python 3.13兼容)
   - 模型大小: tiny, base, small, medium, large
   - 支持中文和英文
   - 离线运行，保护隐私

2. **FunASR** (需要Python 3.9-3.11)
   - 专业级流式识别
   - 更低延迟
   - 需要特定Python版本

### 性能调优

在 `assets/audio_config.json` 中可以调整：

```json
{
  "full_duplex": {
    "whisper_model": "base",        // 模型大小 (tiny/base/small/medium/large)
    "vad_threshold": 0.5,           // 语音检测阈值
    "interruption_timeout": 0.2,    // 打断响应时间(秒)
    "min_speech_duration": 1.0,     // 最小语音长度(秒)
    "max_silence_duration": 2.0     // 最大静音时长(秒)
  }
}
```

## 🔧 故障排除

### 常见问题

**问题**: 语音识别不工作
**解决**:
1. 检查麦克风权限
2. 确认麦克风设备正常
3. 查看系统日志中的错误信息
4. 尝试重启全双工模式

**问题**: 识别延迟太高
**解决**:
1. 使用更小的Whisper模型 (tiny/base)
2. 确保有足够的系统资源
3. 关闭其他占用CPU的程序
4. 考虑使用GPU加速

**问题**: 回音或噪音
**解决**:
1. 使用耳机而不是扬声器
2. 调整麦克风音量
3. 选择更好的音频设备
4. 调整VAD阈值

### 性能优化

**CPU优化**:
- 使用 `tiny` 或 `base` Whisper模型
- 调整音频块大小
- 限制并发请求数量

**内存优化**:
- 选择较小的模型
- 定期清理音频缓冲区
- 监控内存使用情况

**延迟优化**:
- 使用GPU加速 (如果可用)
- 调整音频采样率
- 优化网络连接

## 📊 技术细节

### 系统架构

```
用户语音 → 麦克风 → VAD检测 → ASR识别 → 文本处理 → AI响应
    ↑                                                    ↓
    └─────────────── 智能打断机制 ←─────────────────────────┘
```

### 性能指标

- **识别延迟**: < 500ms (Whisper base模型)
- **打断响应**: < 200ms
- **准确率**: > 90% (清晰语音)
- **资源占用**: 2-4GB RAM (取决于模型)
