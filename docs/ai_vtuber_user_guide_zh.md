## 🎯 系统概述

AI VTuber 智能控制中心是一个集成化的虚拟主播管理系统，提供：

### ✨ 核心功能
- **智能对话**: 基于 Ollama LLM 的自然语言对话
- **Live2D 动画**: 与 VTube Studio 集成的实时表情控制
- **语音合成**: 支持 GPT-SoVITS 和 Edge-TTS 双引擎
- **智能内存**: ChromaDB 驱动的长期记忆系统
- **Agent 模式**: 视觉分析和自动操作能力
- **全双工对话**: 实时语音识别和打断支持

### 🎨 界面特色
- **现代化设计**: 深色主题，粉色强调色
- **响应式布局**: 适配不同屏幕尺寸
- **智能提示**: 完整的鼠标悬停工具提示
- **分类管理**: 功能按类别组织，便于使用

## 🔧 故障排除

### 常见问题

#### 连接问题
```
问题: Ollama 连接失败
解决:
  1. 确认 Ollama 服务运行 (ollama serve)
  2. 检查端口 11434 是否被占用
  3. 确认模型已下载
  4. 重启 Ollama 服务

问题: VTube Studio 连接失败
解决:
  1. 启动 VTube Studio
  2. 启用 API 插件
  3. 检查端口 8001
  4. 重新认证插件

问题: GPT-SoVITS 连接失败
解决:
  1. 启动 GPT-SoVITS 服务
  2. 确认端口 9880 可用
  3. 检查模型文件
  4. 系统自动切换到 Edge-TTS
```

#### 性能问题
```
问题: 响应速度慢
解决:
  1. 启用流式响应
  2. 启用分句处理
  3. 启用音频缓存
  4. 启用系统预热
  5. 检查系统资源

问题: 内存使用过高
解决:
  1. 清理内存数据
  2. 调整缓存大小
  3. 重启系统
  4. 检查内存泄漏

问题: 音频延迟高
解决:
  1. 调整音频缓冲区
  2. 选择合适的音频设备
  3. 启用音频优化
  4. 检查系统负载
```

#### Agent 问题
```
问题: Agent 坐标不准确
解决:
  1. 打开 Agent Debugger
  2. 使用 "测试中心点击"
  3. 调整 DPI 缩放因子
  4. 重新校准坐标

问题: Agent 决策错误
解决:
  1. 使用单步执行测试
  2. 查看原始分析数据
  3. 检查视觉模型状态
  4. 调整提示词

问题: Agent 操作失败
解决:
  1. 检查目标应用状态
  2. 确认操作权限
  3. 调整操作延迟
  4. 使用调试模式
```
