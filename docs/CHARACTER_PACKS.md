# 角色包

角色包保存人格设定、稳定档案 ID、版本、作者与使用条件，便于在不同场景和外形下复用。图片外形继续使用独立的 [外形包](APPEARANCE_PACKS.md)，角色记忆按 [档案 ID](PERSONA_MEMORY.md) 隔离。

## 使用已有角色

桌面展开“角色设置（新手）→ 角色包（导入 / 导出）”，输入文件路径，点击“导入为草稿”。可使用仓库提供的两个示例：

- `config/characters/companion.toml`：喜欢倾听的“小艾”，身份为 `aiex.companion`。
- `config/characters/host.toml`：轻快的主持人“阿星”，身份为 `aiex.host`。

导入只修改编辑草稿。检查名称、语气、提示词与档案 ID，再点击“预览并请求确认”；确认窗口展示编译后的完整提示词，点击“确认应用”才会请求服务切换。外形旁的名字和运行策略面板继续显示已确认的当前角色。

相同 ID 的编辑保留短期对话和长期记忆；不同 ID 切换到另一份记忆范围。导入相同 ID 的包会复用本机该角色的既有记忆。要创建独立角色，先为草稿填写新的 ID。回复进行中会拒绝应用，可在回复结束或手动打断后重试。

## 保存自己的角色

编辑角色后，在角色包区域填写作者、使用条件和一个新的目标文件路径，点击“导出当前草稿”。也可以填写已有文件夹，导出时在里面创建 `character.toml`。目标父目录必须已经存在。

导出保存点击当时的草稿，不要求先应用，也不会切换运行中的角色。已有文件一律拒绝覆盖，修改版请换一个文件名，并按需要增加角色版本。保存采用创建新文件和同步落盘；失败不会覆盖原文件。

文件只包含下面列出的字段，不附带模型地址、API 密钥、控制令牌、设备配置、图片文件或私人记忆。人格提示词和禁忌仍是你主动编辑的内容，分享前请检查其中是否写入了私人信息。

## 格式 v1

角色包当前是 UTF-8 TOML 文件，也支持含 `character.toml` 的文件夹。最小示例：

```toml
schema_version = 1
author = "你的名字"
license = "填写使用与分享条件"

[persona]
profile_id = "my.friend"
revision = 1
name = "我的伙伴"
system_prompt = "喜欢认真倾听，不编造共同经历。"
tone = "温暖、自然、简洁"
taboos = []
live_mode = "controlled"
```

`schema_version` 表示包协议版本，`persona.revision` 表示人格设定版本；二者不是同一个概念。`persona` 中的七个字段全部必需，作者和使用条件可省略。ID 按原字符串精确匹配，支持中文，不被用作文件路径。

清单不超过 64 KiB。版本、字段、人格边界和编译后的提示词均会检查；禁忌最多 64 条。未知字段会被拒绝，避免拼写错误或未支持的配置被悄悄忽略。读取和保存都在后台执行；无效导入保留现有草稿，读写期间暂停再次导入和编辑，避免延迟结果覆盖后续修改。

## 当前边界

- 导入/应用不改写服务启动配置，重启仍使用 `[persona]` 中的初始角色。自动恢复选中角色与角色列表尚未实现；角色、外形及显示偏好可通过[场景包](SCENE_PACKS.md)一起保存、手动重载。
- 包不会自动启用输入源、改变模型或声音，也不运行脚本；`live_mode` 保留为人格字段，不能替代服务层的直播行为配置。
- 暂不支持压缩包、在线素材库、依赖下载和可视化节点编排。当前可独立选择角色包与图片外形包，再用桌面场景面板保存组合；声音与行为尚未加入场景包。
- 角色版本尚无冲突合并或降级迁移机制；应用前需自行检查版本与设定。
