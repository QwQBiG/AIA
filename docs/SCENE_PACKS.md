# 场景组合

场景包把一份已应用的[角色设定](CHARACTER_PACKS.md)、外形和显示偏好放在一起。可以分别更换人格与外形，再保存喜欢的组合；场景 ID 只标识组合，记忆继续由角色的 `profile_id` 隔离。

## 载入与保存

在桌面展开“场景组合（保存 / 载入）”，填写场景文件夹或 `scene.toml` 路径，点击“载入并预览”。仓库提供两个示例：

- `config/scenes/quiet`：小艾与蓝色光球，减少动态效果。
- `config/scenes/host`：阿星与暖色 2D 伙伴，保留动态效果。

程序先在后台检查整个包并解码图片，随后展示角色提示词与外形偏好。点击“确认应用”后，服务确认角色切换才会更新外形。预览和取消保留当前组合与原编辑草稿；回复进行中被服务拒绝时也保留当前组合。

保存时，填写场景 ID、名称和一个**尚不存在的文件夹**路径，点击“保存当前组合”。上级目录必须已经存在；已有目录不会覆盖。保存采用点击当时已生效的角色与显示偏好，未应用的人格草稿不会混入。

图片角色会将源外形包与全部已声明图片复制到场景中，保留图片作者和使用条件。保存时会重新读取并校验源素材；如果源文件已修改，导出的是修改后的素材。要确认最终视觉效果，可重新载入导出的场景。源素材缺失或损坏时保存失败；完成后移动整个场景文件夹仍可载入，不再依赖原素材目录。

## 重新打开时恢复同一个组合

应用并调整好角色和外形后，在场景面板的“启动时的组合”中点击“将当前组合设为启动组合”。桌面会记住当时已生效的角色快照、外形、配色、图片大小和动态偏好；设置通过桌面持久化存储提交保存。以后临时修改外形或编辑草稿不会更新这个快照，需要再次点击设置才会替换。

- 本次由桌面新启动后台服务时，先检查资源，等连接与角色状态同步后自动请求恢复；服务确认后才应用外形。
- 使用 `--connect-only` 或复用已运行的服务时，先展示恢复预览，确认后才请求切换；取消可继续使用当前服务。
- 资源缺失、配置损坏或服务拒绝时显示失败提示，保留已记住的组合，不循环重试。修复资源后可点击“重新载入启动组合”，再次预览并确认。
- 点击“关闭启动恢复”会移除这份配置的启动选择；不会修改服务 TOML 中的初始人格。

恢复过程中可以编辑消息，完成或取消切换后才能发送，避免消息进入错误的角色。设置按**服务配置文件的绝对路径与控制地址**分别保存；移动配置文件或修改控制地址后，需要在新位置重新设置启动组合。

启动选择保存在本机桌面设置中，图片使用本机绝对路径，重开时会重新读取素材；它不是一份新的可分享资源包。要保存可移动的图片副本，先导出场景，再载入导出的场景并设为启动组合。这里只恢复当前版本支持的角色与外形，不恢复运行中的回复或语音。

## 格式 v1

场景是包含 UTF-8 `scene.toml` 的文件夹，图片场景还包含 `appearance/appearance.toml` 与对应 PNG/JPEG。内置外形不需要附带图片文件。

```toml
schema_version = 1
id = "my.scene"
name = "我的组合"

[appearance]
body = "orb"
accent = [110, 170, 225]
reduced_motion = true
scale = 0.8

[character]
schema_version = 1
author = "你的名字"
license = "填写使用与分享条件"

[character.persona]
profile_id = "my.friend"
revision = 1
name = "我的伙伴"
system_prompt = "喜欢认真倾听，不编造共同经历。"
tone = "温暖、自然、简洁"
taboos = []
live_mode = "controlled"
```

`body` 支持 `companion`、`orb`、`images`、`hidden`；`scale` 范围为 0.25–1，仅影响图片大小。图片场景必须在 `[appearance]` 中填写 `package = "appearance/appearance.toml"`，其他外形不能声明此路径。

场景 ID 使用不超过 128 字节的英文字母、数字、点、下划线或短横线；名称不超过 128 个字符。清单最多 128 KiB，内嵌角色继续遵守角色包限制。未知字段和不支持的版本会被拒绝。资源只能使用包内相对路径，不能引用绝对路径、上级目录或网络地址；图片继续遵守外形包的文件大小和像素限制。

导出创建新目录，先写资源，最后写场景清单；普通写入错误会清理本次创建的文件。进程突然终止可能留下不完整目录，再次保存需使用新的目标目录。

## 当前范围与验证

这一版组合角色设定、内置/图片外形、配色、图片大小和动态偏好。角色设定是快照，修改原角色包不会自动更新已有场景。服务凭据、模型配置、声音、输入源、自动行为和私人记忆不随场景导出；提示词本身仍属于用户编辑的内容。

场景应用不改写服务启动配置；没有设置启动组合时，角色仍由原配置决定，外形偏好沿用桌面现有保存机制。已设置的启动组合按上面的恢复规则运行。角色列表、声音/行为包、网页与 VRM 载体继续按[演进计划](DIGITAL_HUMAN_ROADMAP.md)实施。

连接超时可能发生在服务已接受切换之后，此时客户端无法确认远端结果，会保留原外形并显示未确认提示；恢复连接后检查当前角色，再重新应用场景。这一版没有跨进程的持久事务恢复。

自动测试覆盖格式与示例、拒绝覆盖、资源随包迁移、原图片移除后重载、损坏图片拒绝、后台导入进入确认、取消/断线/服务拒绝保留当前组合，以及收到对应确认后才提交外形。界面测试在无窗口环境执行；完整前台点击与跨机器使用仍待单独验收。

启动恢复的无窗口测试覆盖本机设置往返与配置隔离、无效记录保留、等待连接和角色同步、对应命令确认后恢复外形、已有服务需确认、失败不重试、草稿不进入启动快照、临时外形不覆盖启动选择，以及恢复期间保留尚未发送的输入。
